# Instructions

Task- and workflow-level instructions for agents working on this project.

One file per instruction, kebab-case. Referenced from `AGENTS.md` when relevant.

- `adding-a-component.md` — add a component, control, field or hook. Covers the folder
  layout, exports, tests, the **required per-component README**, and the verification gates.
- `changing-a-component.md` — modify an existing one, and keep its README in step.
- `local-development.md` — link the library into a local WordPress site for testing.
