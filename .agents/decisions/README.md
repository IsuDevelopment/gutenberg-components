# Decisions (ADRs)

One file per architectural decision. Keep them short and dated.

Naming: `NNNN-short-title.md` (e.g. `0001-standalone-library.md`).

Template:

```md
# NNNN — <title>

- Status: proposed | accepted | superseded
- Date: YYYY-MM-DD

## Context
Why this decision is needed.

## Decision
What we decided.

## Consequences
Trade-offs and follow-ups.
```
